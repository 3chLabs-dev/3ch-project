# 우리운세 소개 페이지

정적 소개 페이지입니다. 우리리그 웹 프로젝트의 `public/wooriwoonse/`에 이 폴더의 내용을 복사하면 아래 주소로 서비스할 수 있습니다.

- `https://woorileague.com/wooriwoonse/`

약관 링크는 `/wooriwoonse/terms`, `/wooriwoonse/privacy`입니다. 우리리그 웹 프로젝트의 React 라우터가 이 두 경로에서 우리운세 현행 약관을 표시합니다.

## 배포 파일

- `index.html`
- `styles.css`
- `script.js`
- `assets/app-icon.png`
- `assets/logo.png`

스토어 출시 후 `index.html`의 `Android 앱 출시 준비 중` 영역을 실제 다운로드 링크로 교체하면 됩니다.
